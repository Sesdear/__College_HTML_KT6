# КТ 6 — CSS Grid

Вариант 4: дашборд «Панель».

Для запуска откройте `index.html` в браузере. Данные демонстрационные.

HTML и CSS находятся в отдельных файлах. Каркас построен на `grid-template-areas`, каталог — на `repeat(auto-fit, minmax(220px, 1fr))`. При ширине до 768px каркас перестраивается в одну колонку.
